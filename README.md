## Introduction

前端项目 本设计文档基于 Spring Boot + MySQL + Flowable + Vue 技术栈，设计一套企业级 ERP 底层框架。该框架将在现有 RuoYi-flowable 基础上进行增强，实现组织架构管理、权限控制、工作流引擎与可视化表单设计器的深度集成，支持业务单据的全生命周期管理。

## Install and Use

1. Get the project code

```bash
git clone https://github.com/6Yolo6/emp-vben-front.git
```

2. Install dependencies

```bash
npm i -g corepack
pnpm install
```

3. Run

```bash
pnpm dev
```

4. Build

```bash
pnpm build
```
